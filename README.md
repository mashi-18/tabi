# Tabi ✈️ 旅のしおりアプリ

行きたい旅行を「旅のしおり」として作り込める Web アプリです。
旅程（タイムスケジュール）・移動や宿泊などの詳細情報・写真アルバム・メモをまとめて管理できます。<br>
<a href="https://mashi18.pythonanywhere.com">Tabiへのリンク</a>

すべて無料のソフトウェア（Flask + SQLite）で動作し、サーバー代もかかりません。

## 主な機能

- **一覧 + 詳細ページ**構成。一覧から旅を選ぶと「旅のしおり」詳細ページが開く
- **検索**：旅行名・行き先・メモに加え、旅程の予定や詳細情報も横断検索
- **ステータス絞り込み**：行きたい / 計画中 / 行った
- **タイムスケジュール**：Day1・Day2…と日付ごとに時刻＋予定を管理
- **詳細情報**：移動 / 宿泊 / 食事 / その他のカテゴリで、必要な分だけ追加
- **アルバム**：1つの旅に写真を複数枚アップロード、先頭写真は一覧のカバーに
- **メモ**：詳細ページの一番下に表示
- 旅行の **追加 / 編集 / 削除**（削除時は関連データと写真も自動で片付け）

## 使用技術

| 分類 | 技術 |
| --- | --- |
| 言語 | Python 3 |
| Web フレームワーク | Flask |
| データベース | SQLite（標準ライブラリ `sqlite3`、4テーブルのリレーション設計） |
| テンプレート | Jinja2 / HTML / CSS |

## ファイル構成

```
travel_plan-main/
├── app.py            # Flask アプリ本体（画面とルーティング）
├── travel_db.py      # データベース操作（trips / schedule / details / photos）
├── templates/        # 画面の HTML（Jinja2 テンプレート）
│   ├── base.html     # 共通レイアウト・デザイン
│   ├── index.html    # 一覧 + 検索
│   ├── detail.html   # 旅のしおり（詳細ページ）
│   └── form.html     # 追加・編集フォーム
├── static/uploads/   # アップロードした写真の保存先
├── requirements.txt  # 依存パッケージ
└── README.md
```

画面処理（`app.py`）とデータ処理（`travel_db.py`）を分離し、見通しのよい構成にしています。

## データベース設計

```
trips (旅行) 1 ──< schedule_items (旅程: Dayごと)
             1 ──< details        (詳細: カテゴリ別)
             1 ──< photos         (アルバム)
```

子テーブルは外部キー＋ON DELETE CASCADE で、旅行を消すと関連データも自動削除されます。

## 動かし方（ローカル）

```bash
# 1. 依存パッケージをインストール
pip install -r requirements.txt

# 2. アプリを起動
python app.py

# 3. ブラウザで開く
#    http://127.0.0.1:5000
```

データベース（`travel.db`）は初回起動時に自動で作成されます。

## 工夫した点

- 画面とデータ処理を分離し、保守しやすい構成にした。
- SQL は必ずプレースホルダ（`?`）を使い、SQL インジェクションを防止。
- 外部キーとカスケード削除で、データの整合性を保った。
- アップロード画像は拡張子を検証し、ファイル名を一意化して保存。
